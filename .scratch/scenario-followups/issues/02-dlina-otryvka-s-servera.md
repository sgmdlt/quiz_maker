# 02: Длина отрывка приходит с сервера

**What to build:** окно отрывка на волне трека и метка вопроса в списке треков получают длину и номер от сервера, по тем же правилам, что сценарий ролика (время раунда, второй отрывок, «Три попытки»). Если поменять время на вопрос в раунде или задать начало второго отрывка, окно на волне меняется так же, как отрывок в ролике. Своего правила расчёта длины в интерфейсе нет.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Длина окна на волне совпадает с длиной отрывка в сценарии для обычного трека и для трека с двумя отрывками
- [x] Смена времени раунда обновляет окна всех его треков
- [x] Правило расчёта длины отрывка в интерфейсе удалено
- [x] Тест на сервере: длина и метка, которые отдаются интерфейсу, совпадают со сценарием

## Comments

Метку вопроса интерфейс не показывает (в списке треков — порядковый номер для перетаскивания), поэтому с сервера приходит только длина отрывка: поле `clips` в данных квиза и в ответах на PATCH квиза и трека. Проверено на живом сервере: время раунда 12 с → окна 12 с, второй отрывок → 6 с.
