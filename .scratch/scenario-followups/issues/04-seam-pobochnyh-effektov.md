# 04: Seam для побочных эффектов сборки

**What to build:** сборка ролика получает диктора, нарезку отрывков и кодировщик как зависимости. В работе это настоящие edge-tts/Piper, ffmpeg и x264; в тестах — заглушки: тишина заданной длины и запись кадров в память. Это позволяет быстро проверить звук слайдов (звук ответа в режимах «тот же отрывок», «продолжение», «тишина», два отрывка, видео ответа) и порядок кадров, не запуская ffmpeg. Полная сборка через ffmpeg остаётся одним сквозным smoke-тестом.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Тесты звука ответа во всех трёх режимах, двух отрывков и видео ответа идут без ffmpeg
- [ ] Один сквозной тест собирает настоящий ролик через ffmpeg
- [ ] Полный прогон тестов заметно быстрее нынешних ~100 с; цифры до/после в Comments
- [ ] Пробный ролик реального квиза побитово совпадает с прежней сборкой (звук и кадры)
