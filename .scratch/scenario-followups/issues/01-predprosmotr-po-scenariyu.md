# 01: Предпросмотр по сценарию

**What to build:** предпросмотр в конструкторе (вкладка «Тексты», выбранный раунд, выбранный трек) показывает ровно те слайды, что попадут в ролик: те же подписи с подстановками, метки «Вопрос 1.2 из 5» в «Трёх попытках», паузу перед вопросом, слайд ответа на тройку вопросов, заставки раунда и блока ответов. Слайды для предпросмотра берутся из сценария ролика и рисуются той же функцией отрисовки слайда, что и при сборке. Собственные копии правил раунда в предпросмотре (подсчёт «всего», номер тройки, пауза перед отсчётом) удалены.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Кадры предпросмотра для обычного раунда и «Трёх попыток» совпадают по подписям с кадрами ролика
- [ ] В предпросмотре нет своих вычислений «всего», номера тройки и паузы — только сценарий
- [ ] Предпросмотр без скачанного трека по-прежнему работает (заглушка вместо спектра)
- [ ] Тесты проходят; есть тест предпросмотра без ffmpeg-сборки ролика
