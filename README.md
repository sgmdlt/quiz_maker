# Конструктор видео-квизов «Угадай песню»

Вставляете ссылки на YouTube, отмечаете узнаваемые моменты, настраиваете оформление,
и на выходе получается готовое видео для YouTube: обложка ролика, описание с главами и ответы.

**Как устроен ролик:** заставка → все вопросы → экран «Ответы» → все ответы → финал.
- **Вопрос:** круговой визуализатор по настоящему спектру отрывка. Кольцо прорисовывается
  по часовой стрелке, потом убывает, как таймер. В центре обратный отсчёт.
- **Ответ:** обложка релиза, название, исполнитель, альбом и год. Звучит тот же отрывок.

## Установка (Ubuntu 24.04, один раз)

Из системы нужен только ffmpeg. Всё остальное (Pillow, numpy, yt-dlp и JavaScript-движок deno,
без которого YouTube отдаёт не все треки) uv ставит в отдельное окружение внутри папки проекта.

```bash
sudo apt install ffmpeg
curl -LsSf https://astral.sh/uv/install.sh | sh   # если uv ещё нет; потом откройте терминал заново
cd quiz-maker
uv sync
```

Точные версии зависимостей записаны в `uv.lock`, поэтому `uv sync` на любом компьютере ставит то же,
на чём всё проверено. Окружение лежит в папке `.venv` — удалите её, и следа не останется.

YouTube регулярно что-то меняет. Если скачивание перестало работать, обновите yt-dlp:

```bash
uv sync -P yt-dlp -P yt-dlp-ejs -P deno
```

## Запуск

```bash
cd quiz-maker
uv run make_quiz.py serve
```

Откроется браузер на `http://127.0.0.1:8765`. Конструктор работает только на вашем компьютере.
Остановить можно клавишами Ctrl+C в терминале.

## Как собрать выпуск

1. **Треки.** Вставьте ссылки, по одной в строке, и нажмите «Добавить». Треки скачаются сами.
   - Если в ссылке есть время (на YouTube: «Поделиться» → «Начало»), отрывок начнётся с него.
   - Строка может содержать больше данных: `ссылка | 1:05 | Название | Исполнитель | подсказка`.
   - Свои mp3 можно перетащить в поле или указать путём: `/home/я/Музыка/песня.mp3 | 0:48`.
   - Название и исполнитель заполнятся из данных видео. У треков из YouTube Music они точные,
     у клипов разбирается заголовок «Исполнитель - Песня (Official Video)». Проверьте и поправьте.
2. **Моменты.** У каждого трека есть волна, жёлтое окно на ней — отрывок для вопроса.
   - Перетащите окно мышью. Двойной щелчок по волне ставит начало в это место.
   - Щелчок по волне включает трек с этого места. Пока он играет, кнопка «Отметить» ставит
     начало на текущий момент.
   - ▶ проигрывает отрывок ровно той длины, что будет в ролике. Пробел ставит на паузу и снимает с неё.
3. **Обложки** находятся сами: вшитая в файл → Deezer → iTunes → кадр из YouTube → пластинка.
   Если нашлась не та, нажмите на обложку или перетащите на неё свою картинку.
4. **Тексты, Оформление, Визуализатор.** Справа живой предпросмотр всех экранов. Он сам
   перерисовывается после каждого изменения и показывает трек, который вы сейчас правите.
5. **Сборка.** Сначала соберите пробный ролик из двух песен (секунд 20–30), потом весь квиз.
   Там же можно скачать видео и обложку ролика и скопировать описание.

## Где что лежит

```
quiz-maker/
  pyproject.toml      зависимости для uv; uv.lock — их точные версии
  make_quiz.py        запуск: serve и команды для терминала
  server.py           веб-сервер конструктора
  web/index.html      интерфейс
  quiz_core.py        проекты, экраны, предпросмотр, сборка видео
  spectrum_ring.py    визуализатор: анализ спектра и анимация кольца (все настройки — RingConfig)
  covers.py           поиск обложек
  youtube.py          скачивание через yt-dlp
  projects/<квиз>/project.json   ваш квиз: треки, тексты, шрифты, цвета, визуализатор
  projects/<квиз>/output/        готовые видео, обложки, описания, кадры предпросмотра
  library/            общее для всех квизов: скачанные треки, шрифты, картинки, обложки
```

Скачанный трек хранится один раз: если он попадёт в следующий квиз, второй раз скачиваться не будет.
Для серии выпусков удобна команда меню «⋯ → Копия этого квиза»: оформление сохранится, треки замените.

## Из терминала (без браузера)

```bash
uv run make_quiz.py new "Угадай хит 2000-х" --links ссылки.txt   # создать квиз и скачать треки
uv run make_quiz.py list                                          # список квизов
uv run make_quiz.py add ugadai-khit-2000-kh ещё.txt               # добавить треки
uv run make_quiz.py preview ugadai-khit-2000-kh                   # кадры экранов и лист всех ответов
uv run make_quiz.py build ugadai-khit-2000-kh --limit 2           # пробный ролик
uv run make_quiz.py build ugadai-khit-2000-kh                     # весь квиз
```

Файл со ссылками устроен так же, как поле в конструкторе (пример — `ссылки-пример.txt`).
Старая таблица `quiz.csv` (file,start,title,artist,…) тоже подходит.

## Если что-то не так

- **«YouTube просит подтвердить, что вы не бот».** В конструкторе откройте «Треки → Настройки
  скачивания» и впишите `--cookies-from-browser firefox` (или `chrome`), чтобы yt-dlp взял вход из браузера.
- **Трек не скачивается или звук неполный.** Обновите yt-dlp (команда выше) и проверьте значок
  инструментов в правом верхнем углу конструктора.
- **«yt-dlp не установлен» или «нет deno».** Скорее всего, конструктор запущен через `python3`,
  а не через `uv run` — тогда он не видит окружение проекта. Запускайте `uv run make_quiz.py serve`.
- **Порт занят.** `uv run make_quiz.py serve --port 9000`.
