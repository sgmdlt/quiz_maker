# Оформление одно на все квизы

Оформление (цвета, шрифты, визуализатор, тайминги, подписи) хранится в `library/theme.json` и общее для всех квизов. В `project.json` его нет: при загрузке оно накладывается на квиз, при сохранении вырезается из него. Так попросил автор: все ролики канала должны выглядеть одинаково. Поэтому правка цвета в одном квизе меняет все квизы — это сделано намеренно. Тексты квиза, озвучка, фоновая музыка и раунды у каждого квиза свои.
